# Quiz APP

In this web app, you can test yourself with 10 randomly selected questions from various categories and difficulty levels.

### 🔗 Links

👉 **[Go Live Site](https://quiz-app5039.netlify.app/)** <br>
👉 **[Go API](https://the-trivia-api.com/)**

## 🛠️ Built With

- **React**
- **Context API**
- **Mobile-first workflow**

### About The Project

I don't have the actual design file so the layout is not pixel-perfect. The website is responsive only 1440px and 375px screen sizes. Implementation focuses on:

- Clean and modern CSS
- Good accessibility practices
- Keyboard-friendly interactions

## 🚀 Installation

1. Clone the repository:

```sh
git clone https://github.com/yusufardapeker/quiz-app.git
cd quiz-app
```

2. Install dependencies:

```sh
npm install
```

3. Start the development server:

```sh
npm run dev
```

4. Open your browser and go to http://localhost:5173
